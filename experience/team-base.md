# 配队基础经验

## 基础

- 只在自己的资料库范围内推荐：角色、光锥、遗器都用查询结果里真实存在的名字，不要凭印象编造。
- 配队建议要说清每个位置的作用，而不是只列四个名字。
- 涉及数值时先查再写：角色满级属性、行迹加成、光锥叠影、遗器套装效果都可以用 `--role`、`--lightcone`、`--relicset` 查到。
- 用户没说自己的角色池时，先按通用队伍给方案，再补一句"如果有 X 可以换成 Y"。
- 用户提到自己已经练了谁、抽了谁，优先用这些角色，不要推荐他没有的角色。
- 不确定的机制不要编。
- 遗器建议先确认套装是内圈还是外圈：只有 2 件套效果的是内圈，同时有 2 件与 4 件效果的是外圈。
- 命座是依次解锁的，顺序：有本体（0命）->1命（有第一个命座）->…
- 专武：一般指第一张推荐光锥，即查询时返回的推荐光锥，只有5星非开拓者的角色有专武。某角色（a+b）表示该角色的命座数为a，专武叠层为b（0为没有专武）。
- 用户没有说角色命座时，四星角色和开拓者默认满命，其他五星角色最多假设有2命，且在配队时尽可能降低金数（即命座数）需求。
- 由于战斗有行动值限制，所以需要再有限行动值内打出更多伤害，且尽量恰好在某一回合结束前打出伤害，最大化利用（因为一回合没结束时是不计消耗回合的）。

## 遗器光锥
- 每个角色要携带一个光锥和一套完整遗器（4+2），适配的光锥可能改变角色战斗逻辑。
- 完整遗器的数值参考 `--teamKnowledge` 中给出的遗器词条，一般认为主C有30个有效词条，辅助根据有效词条的种类数取有效词条15~30个，且估计时不能取某个副词条非常多。若用户提供了具体面板，则按用户给的计算。**一定要计算遗器提供的词条和效果！**
- 面板估算按 `--teamKnowledge` 第 2.4 节的口径走：角色基础 → 光锥基础 → 行迹 → 套装 → 主词条 → 副词条 → 条件加成；副词条初始值与每次强化都按三档中值算，得到的是「期望面板」。
- 条件生效的套装效果（速度 ≥120 再加攻、速度 ≥135/160 再加伤等）先按不满足算，速度算出来达标再加回去，不要一开始就加。
- 主C常用副词条分配（30次强化）：暴击率8、暴击伤害8、攻击%6、速度4、生命%4；不吃暴击的角色把暴击换成属性伤害%或治疗量加成%。
- 辅助常用分配（20次强化）：速度6、暴击率2、暴击伤害2、效果命中4、效果抵抗4、攻击%2。
- 估算面板时不要把队友增益、忆灵、只持续1回合的增伤算进去，那些属于覆盖率与排轴部分。
- 推荐光锥只表示该光锥可能是该角色专武，**不一定是最适配该角色的光锥**，不得直接套用。
- 同谐角色要额外考虑是否适配光锥“舞！舞！舞！”，该光锥提供的全队行动提前24%（叠5）的收益很高。能较高频释放终结技的角色外圈考虑风套（翔鹰套）。
- 需要辅助角色尽早上拐力时考虑内圈遗器“生命的翁瓦克”。
- 没有说明时，四星角色默认满星魂，四星及以下光锥默认叠5，五星光锥均只有一张叠1，“记一位星神的陨落”“星海巡航”“记忆的质料”“孤独中疗愈”“不息的演算”“记忆永不落幕”“欢愉满溢祝福”是一张叠5。

## 配队
- 一般情况下，考虑标准四人队伍，一号位主C，二号位副C/辅助，三号位辅助，四号位生存。若用户指出带生存伤害不够/要追高分、0T，则考虑三拐。
- 对于记忆、欢愉命途的配队，可以考虑四人同一命途，其它情况多没有必要。
- 一般情况下，巡猎、毁灭、智识命途是主C/副C，同谐命途是辅助，虚无命途是副C/辅助，丰饶、存护命途是生存。记忆、欢愉命途的角色各种情况均有可能。
- 部分角色由于机制契合，能尝试三拐，即四号位也换成辅助。
- 队伍中有特殊机制的队伍，尽量让更多的角色参与到该机制中。
- 攻击、增伤、爆伤等词条有边际效应，配队时要考虑。
- 考虑配队时，应当先考虑辅助能提供什么，需要主C具备哪些特点，再去找适配的主C；对于需要同时配出多路队伍的关卡，还要考虑不同队伍间的实力分配，不能有一间过弱。
- 当用户提供敌方的具体情况时，优先考虑能快速破除敌方机制的角色，同时考虑敌方抗性和弱点，尽可能不要让主C打对应属性有高抗性的怪而是找BOSS有对应弱点的。若没有其他可选主C，则考虑让副C/辅助能针对对应弱点，并考虑三拐。
- 三拐时队伍中最好有一个角色可以提供一定生存能力，如自带减伤或回复、生命倍率（或有角色的主词条可以选生命%、防御%）、记忆命途（忆灵可以不断复活），且一般三拐时要有至少一个辅助具有拉条（使队友行动提前）的能力。
- 队伍中角色的机制若能相互触发，则称为队伍逻辑自洽，优先考虑。
- 配队时同步考虑排轴，见下。

## 排轴
- 实际游戏时，还需要对角色的行动顺序进行规划。参考 `--teamKnowledge` 中给出的行动值相关词条，根据用户提供的数据或自己估计，按规则设计一套能最大化行动顺序的逻辑。
- 排轴时可以假定我方角色速度能够调整（注意忆灵速度和阿哈时刻速度变化），但不要假设过高的速度。一般主C词条优先双爆（或其他提升伤害的词条），在需要时添加少量速度。
- 要考虑我方辅助提供的效果的覆盖率，尽可能保证全程覆盖，至少保证主C爆发输出时尽可能上满buff。
- 特定情况下，可以在终结技满能量时先不释放，从而改变输出或效果触发时机。
- 辅助大多能通过遗器获得较高速度，通常认为如果只追速度词条，在不考虑技能加成时可以达到160~180，高练度可以达到190左右；若同时还需要另一词条，则认为速度可达到130-160左右。一般常见速度阈值为134（忘却之庭首轮2动）、142（忘却之庭带叠5“舞！舞！舞！”、翔鹰套和翁瓦克首轮3动）、160（忘却之庭两轮4动、带叠5“舞！舞！舞！”和翁瓦克首轮3动）、174（带翁瓦克忘却之庭首轮3动）
- 主C的遗器副词条一般多选则暴击率、暴击伤害（如果伤害能暴击，否则选择其他增幅伤害的词条）。
- 速度和充能效率存在阈值，若速度无法让角色在规定轮内多一动、满足某个效果或在某个时刻先行动，则是无效速度；充能效率若不能多充出一个终结技，则也无效。但若能多一动，多充出一个大招，则是很大提升。这方面一般考虑辅助。
- 由于被敌方攻击也可以获得少量能量，所以某次行动后若只缺少数点能量，可以标注此处可尝试通过受击补齐能量缺口。注意特殊能量受击不回复。
- 没有特殊说明，能量满后不再回复，不能溢出。
- 排轴时一般针对某项具体深渊的行动值限制，默认忘却之庭，即第一轮150行动值。
- 可根据 `--teamKnowledge` 中给出的行动值相关词条，精确计算角色间的行动先后顺序。
- 覆盖率按 `--teamKnowledge` 第 8 节算：先列主 C 每个输出回合，标注增伤/降防/易伤是否到位，再区分「永远补不上」「这一轮补不上」「顺序不对」三类缺口。主C单次输出占比大时，缺一次buff的损失远大于少动一次。
- 持续回合数在**自己回合结束**时减1，所以「1回合buff」只能覆盖同一次行动，主C若在辅助之后行动就吃不到。要主C吃到，辅助必须比主C早动至少一轮，或给更长持续回合数。
- 「下一次」型增益跟着下一个行动者走，「施放终结技后」型增益给自己加速，这两类在排轴时都要单独标注。
- 永续buff的判断看三点：产出端多久给一次、消耗端能撑几轮、消耗速度不能快过产出速度。产出每2轮1次而消耗每轮1次，就永远缺。
- 卡双BUFF的做法：把「A→C→B」的顺序改成「B→C」，让主C同时吃到两个同源继承增伤，代价是给B加速（翔鹰套「施放终结技后行动提前25%」）。
- 终结技能量满了可以先不放，等主C需要增伤的那一刻插队放；插队不占行动机会，这是终结技最大的价值。
