# 《崩坏：星穹铁道》战斗规则

## 1. 遗器词条

### 1.1 各部位主词条类型

遗器分隧洞遗器（外圈：头部、手部、躯干、脚部）与位面饰品（内圈：位面球、连结绳），不可重复。主词条由部位固定，副词条不会与主词条重复。

| 部位 | 可能的主词条 |
|---|---|
| 头部 | 生命值（固定） |
| 手部 | 攻击力（固定） |
| 躯干 | 生命值%、攻击力%、防御力%、暴击率%、暴击伤害%、治疗量加成%、效果命中% |
| 脚部 | 生命值%、攻击力%、防御力%、速度（固定） |
| 位面球 | 生命值%、攻击力%、防御力%、各属性伤害提高%（物理/火/冰/风/雷/量子/虚数） |
| 连结绳 | 生命值%、攻击力%、防御力%、击破特攻%、能量恢复效率% |

主词条强化至 +15 的满级数值（5 星）：

| 主词条 | +15 数值 |
|---|---|
| 攻击力（固定，手部） | 358.8 |
| 生命值（固定，头部） | 705.6 |
| 速度（固定，脚部） | 25.032（游戏中显示 25） |
| 能量恢复效率 | 19.44% |
| 暴击率 | 32.4% |
| 暴击伤害 | 64.8% |
| 治疗量加成 | 34.56% |
| 效果命中 | 43.2% |
| 生命值% / 攻击力% | 43.2% |
| 防御力% | 54% |
| 击破特攻 | 64.8% |
| 属性伤害提高 | 38.8% |

注：不同来源对脚部速度的取整显示略有差异，计算时以 25 为近似值，精确值以游戏内为准。

### 1.2 副词条机制

- 5 星遗器初始 3 或 4 条副词条；初始 3 条时在 +3 级新增第 4 条；初始 4 条时直接进入强化，因此初始 4 词条多一次成长机会。
- 每 +3 级（+3/+6/+9/+12/+15）触发一次副词条成长：未满 4 条则新增，已满 4 条则在 3 个数值中随机选一档相加。
- 副词条共享池：固定生命值、固定攻击力、固定防御力、生命值%、攻击力%、防御力%、速度、暴击率、暴击伤害、效果命中、效果抵抗、击破特攻。

下表为五星遗器副词条每次成长时三档随机数值（显示值经过向下取整，实际内部值略高）。

| 副词条 | 一档 | 二档 | 三档 |
|---|---|---|---|
| 暴击率 | 2.59% | 2.92% | 3.24% |
| 暴击伤害 | 5.18% | 5.83% | 6.48% |
| 生命值% / 攻击力% | 3.46% | 3.89% | 4.32% |
| 防御力% | 4.32% | 4.86% | 5.40% |
| 速度 | 2.0 | 2.3 | 2.6 |
| 效果命中 / 效果抵抗 | 3.46% | 3.89% | 4.32% |
| 击破特攻 | 6.48% | 7.29% | 8.10% |
| 固定生命值 | 33.87 | 38.10 | 42.34 |
| 固定攻击力 | 16.94 | 19.05 | 21.17 |
| 固定防御力 | 16.94 | 19.05 | 21.17 |

成长示例：暴击率初始 2.92%，一次成长若随机到 3.24%，则变为 2.92% + 3.24% = 6.16%。

## 2. 角色面板数值计算逻辑

### 2.1 攻击力（最常用范式）

战斗内攻击力 = (角色基础攻击力 + 光锥基础攻击力) × (1 + 攻击力百分比加成总和) + 攻击力固定值加成总和

其中：
- 白值 = 角色基础攻击力 + 光锥基础攻击力；
- 百分比加成来源：攻击力% 主词条、攻击力% 副词条、光锥效果、遗器套装效果、行迹、队友增益等，同区内加算；
- 小词条（固定攻击力）在乘法之后直接相加。

### 2.2 生命值、防御力

同一逻辑适用：
生命值 = (角色基础生命 + 光锥基础生命) × (1 + 生命值%总和) + 固定生命值加成总和
防御力 = (角色基础防御 + 光锥基础防御) × (1 + 防御力%总和) + 固定防御力加成总和
速度较为特殊：速度一般为固定值相加，速度%加成以基础速度为基数；战斗内速度 = 基础速度 × (1 + 速度%加成) + 固定速度加成。

### 2.3 双暴

暴击率 = 基础暴击率（通常 5%）+ 暴击率加成总和（遗器、光锥、行迹、队友等），上限 100%。
暴击伤害 = 基础暴击伤害（通常 50%）+ 暴击伤害加成总和。

### 2.4 面板估算：从遗器词条推到面板数值

估算顺序固定：角色基础 → 光锥基础 → 行迹 → 遗器套装 → 遗器主词条 → 遗器副词条 → 光锥/套装的条件加成。

**（1）取基础值**

- 角色 80 级基础属性与行迹加成用 `--role` 查；光锥 80 级基础属性与叠影参数用 `--lightcone` 查；遗器 2 件/4 件套效果用 `--relicset` 查。
- 默认按光锥叠影 1 估算；用户给了叠影数就按他的值。
- 行迹加成是属性伤害%、暴击率%、暴击伤害%、生命%、防御%这些**面板或乘区加成**，要叠加到对应公式里，不是单独一段数字。

**（2）有效词条口径**

「有效词条数」= 该角色用得上的副词条上发生的强化次数。

- 一件 5 星遗器有 5 次强化机会（+3/+6/+9/+12/+15），6 件遗器共 30 次。
- 主 C 若 30 次强化全部落在有用副词条上，称为「30 有效词条」，这是上限。
- 辅助的有效种类少（治疗量加成、击破特攻、效果命中/抵抗这类常常用不上），一般只取 15~30。
- 估算时不要出现「某个副词条非常多」的反常分布（单个副词条超过 10 次就不现实）。
- 用户给了实际面板就按用户的算，不用估算。

**（3）主副词条配比**

主词条按部位固定（见 1.1），一共只有 6 个主词条，其余全是副词条。主 C 常用分配（以 30 次强化为例）：

| 副词条 | 强化次数 | 估算最终值（每档取中值） |
|---|---|---|
| 暴击率 | 8 | 2.92% + 8 × 2.92% ≈ 26.3% |
| 暴击伤害 | 8 | 5.83% + 8 × 5.83% ≈ 52.5% |
| 攻击力% | 6 | 3.89% + 6 × 3.89% ≈ 27.2% |
| 速度 | 4 | 2.3 + 4 × 2.3 ≈ 11.5（脚部主词条 25 另计） |
| 生命值% | 4 | 3.89% + 4 × 3.89% ≈ 19.4% |

不吃暴击的角色（DoT、治疗、护盾位）把暴击的次数换成属性伤害%、治疗量加成%等。

辅助典型分配（以 20 次强化为例）：速度 6 次、暴击率 2 次、暴击伤害 2 次、效果命中 4 次、效果抵抗 4 次、攻击力% 2 次。

估算约定：初始值与每次强化都按三档里的中值算，所以结果是「期望面板」；真实面板因档位随机会有高低差，这是估算与实面板的主要误差来源。

**（4）算例 A：丹恒•饮月（80 级）+ 银河铁道之夜（叠 1，场上 5 个目标）+ 识海迷坠的学者 4 + 太空封印站 2**

输入：

- 角色 1213 丹恒•饮月：生命 574.464、攻击 323.136、防御 168.3、速度 102、暴击率 5%、暴击伤害 50%、能量上限 140；行迹：虚数伤害 +22.4%、暴击率 +12%、生命 +10%。
- 光锥 23000 银河铁道之夜（80 级）：生命 1164.24、攻击 582.12、防御 396.9；效果「每有 1 个敌方目标攻击力 +9%（最多 5 层）」→ 满层 +45%。
- 遗器：学者 4 件（2 件 暴击率 +8%；4 件 战技与终结技伤害 +20%）；太空封印站 2 件（攻击力 +12%；速度 ≥120 时再 +12%）。
- 副词条 30 次强化：暴击率 8、暴击伤害 8、攻击% 6、速度 4、生命% 4。

结果：

| 项 | 算式 | 结果 |
|---|---|---|
| 攻击力 | (323.136 + 582.12) × (1 + 45% + 12% + 12% + 27.2%) + 358.8 | ≈ 2135 |
| 生命值 | (574.464 + 1164.24) × (1 + 10% + 19.4%) + 705.6 | ≈ 2956 |
| 防御力 | (168.3 + 396.9) × (1 + 0%) + 0 | 565.2 |
| 速度 | 102 + 25.032 + 11.5 | ≈ 138.5 |
| 暴击率 | 5% + 12%（行迹）+ 8%（学者 2 件）+ 26.3% | ≈ 51.3% |
| 暴击伤害 | 50% + 52.5% | ≈ 102.5% |
| 能量上限 / 充能效率 | 角色 140；连结绳 19.44% | 140 / 19.44% |

注意：速度 138.5 ≥ 120 时太空封印站那 12% 才生效。条件生效的加成先按不满足算，达标后再加回来，否则会高估。

**（5）算例 B：布洛妮娅（80 级）+ 但战斗还未结束（叠 1）+ 骇域漫游的信使 4 + 生命的翁瓦克 2**

输入：

- 角色 1101 布洛妮娅：生命 574.464、攻击 269.28、防御 246.84、速度 99、暴击率 5%、暴击伤害 50%、能量上限 120；行迹：风伤害 +22.4%、暴击伤害 +24%、效果抵抗 +10%。
- 光锥 23003 但战斗还未结束（80 级）：生命 1164.24、攻击 529.2、防御 463.05；效果「能量恢复效率 +10%（叠 1）、施放终结技时恢复 1 战技点」。
- 遗器：信使 4 件（2 件 速度 +6%；4 件 对我方目标施放终结技时全队速度 +12%，持续 1 回合，不可叠加）；翁瓦克 2 件（能量恢复效率 +5%）。
- 副词条 20 次强化：速度 6、暴击率 2、暴击伤害 2、效果命中 4、效果抵抗 4、攻击力% 2。

结果：

| 项 | 算式 | 结果 |
|---|---|---|
| 速度 | 99 × (1 + 6%) + 25.032 + 16.1 | ≈ 146 |
| 攻击力 | (269.28 + 529.2) × (1 + 11.7%) + 358.8 | ≈ 1251 |
| 生命值 | (574.464 + 1164.24) × (1 + 0%) + 705.6 | ≈ 2444 |
| 防御力 | 246.84 + 463.05 | 709.89 |
| 暴击率 | 5% + 8.8% | ≈ 13.8% |
| 暴击伤害 | 50% + 24%（行迹）+ 17.5% | ≈ 91.5% |
| 充能效率 | 连结绳 19.44% + 翁瓦克 5% + 光锥 10% | ≈ 34.4% |
| 能量上限 | 角色 120 | 120 |

速度 ≥120，翁瓦克那 40% 进场行动提前生效；辅助的暴击率低是正常的，别按主 C 的标准去要求它。

**（6）估算不包含的东西**

队友增益、忆灵、光锥里只在特定回合生效的效果（如银河铁道之夜的弱点击破增伤只持续 1 回合）、祝福/奇物的乘区，都不在面板估算里。面板算完还要按第 3 节算实际伤害，再按第 8 节看效果覆盖率。


## 3. 伤害计算

### 3.1 通用乘区结构

所有伤害类型共享同一套乘区骨架，但不同伤害“吃”哪些乘区不同。核心乘区：
通用伤害 = 基础伤害区 × 增伤区 × 易伤区 × 暴击区（若可暴击）× 防御区 × 抗性区 × 韧性/减伤区 × 特殊乘区
关键原则：除减伤区外，大多数乘区内部为加算。例如增伤 50% 与增伤 30% 同时存在，增伤乘区 = 1 + 0.50 + 0.30 = 1.80，而非 1.50 × 1.30。

### 3.2 传统直伤

直伤 = 技能倍率 × 攻击力（或生命/防御，依技能描述）× 增伤区 × 易伤区 × 暴击区 × 防御区 × 抗性区 × 韧性区 × 减伤区

各乘区定义：

- 增伤区 = 1 + 增伤加成总和（属性伤害提高、造成伤害提高、战技/普攻/终结技伤害提高等）。
- 易伤区 = 1 + 易伤加成总和。
- 暴击区 = 1 + 暴击伤害（暴击时）；未暴击时为 1。
- 防御区 = (200 + 攻击者等级 × 10) / [(200 + 攻击者等级 × 10) + (200 + 受击者等级 × 10) × (1 - 减防% - 无视防御%)]
也可等价写为：防御区 = 1 - 敌人防御力 / (敌人防御力 + 攻击者等级 × 10 + 200)，敌人防御力 = 敌人等级 × 10 + 200。减防与无视防御可叠加，最高将防御区压至 100% 收益上限，不可使敌人防御降至 0 以下。
- 抗性区 = 1 - 敌人该属性抗性 + 抗性穿透 + 抗性降低。抗性可以被压到负数，加减范围约在 ±100% 以内。

### 3.3 怪物常用基础抗性

| 场景 | 该属性基础抗性 |
|---|---|
| 敌人拥有该属性弱点 | 0% |
| 敌人不具有该属性弱点（非弱点） | 20% |
| 敌人额外拥有该属性的“抗性”词条 | 40%（与 20% 叠加后常见为 40%，部分特殊敌人可达 60%） |

注：抗性乘区 = 1 - 抗性。若敌人有 20% 非弱点抗性，则抗性区 = 0.8；若额外 20% 抗性叠加至 40%，则抗性区 = 0.6。抗性穿透与减抗可使抗性为负，此时抗性区 > 1。

### 3.4 韧性/破盾乘区与减伤

未击破弱点时，敌人通常有独立的 10% 韧性减伤，即韧性区/破盾乘区 = 0.9；已击破弱点时为 1.0。
减伤区内部为乘算：若敌人同时拥有多个减伤效果（如 30% 减伤和 50% 减伤），最终减伤系数 = (1 - 0.30) × (1 - 0.50)，而非 1 - 0.80。这是全乘区中唯一内部乘算的乘区。

### 3.5 持续伤害（DoT）

DoT 分为两类，算法不同：

**（1）常规持续伤害**（角色技能/光锥/祝福施加，技能面板有明确倍率）

DoT 单跳 = 攻击力 × DoT 倍率 × 层数 × 增伤区 × 易伤区 × 防御区 × 抗性区 × 韧性/减伤区

常规 DoT 的特点：
- 不吃暴击，双暴区不参与计算；
- 吃增伤区（属性增伤、持续伤害提高等）；
- 吃攻击力乘区。

**（2）击破持续伤害**（由弱点击破触发，如灼烧、触电、风化、裂伤）

击破 DoT 的基础伤害不由攻击力决定，而由击破基数、击破特攻和韧性长度决定。具体公式见 3.6 击破伤害部分，击破持续伤害是击破伤害公式在特定属性下的延时结算形式。
物理击破的裂伤是特殊分支：裂伤伤害 = min{敌人类型系数 × 最大生命值，角色等级基数 × (最大韧值/10 + 2)/4} × 减防/减伤/抗性/易伤乘区。
DoT 的共性：属于负面状态，可参与负面状态计数，可被净化解除；同源同名 DoT 互相覆盖，非同源同名可并存；在目标回合开始时结算。

### 3.6 击破伤害与超击破伤害

**击破伤害**（弱点击破瞬间触发）：

击破伤害 = 击破基数 × 对应属性击破倍率 × (1 + 击破特攻) × (敌人最大韧性长度单位 + 2) ÷ 4 × 易伤区 × 防御区 × 抗性区 × 减伤区
- 80 级角色击破基数约为 3767（部分来源在“削韧值单位变更”后使用 376.7，需根据具体公式语境区分：击破伤害本体通常用 3767 量级，超击破在削韧值单位调整后使用 376.7 量级）。
- 击破特攻同时提高击破伤害、击破持续伤害威力与行动延迟幅度，但不加快削韧速度。

**超击破伤害**：

超击破伤害 = 击破基数 × (1 + 击破特攻) × 技能最终削韧值 × (1 + 超击破伤害提高) × 易伤区 × 防御区 × 抗性区 × 减伤区
80 级超击破基数约为 376.7（与削韧值单位同步调整后的数值）。
击破/超击破的关键乘区特征：不吃增伤区，不吃暴击区；击破特攻、削韧值、超击破伤害提高是核心可控乘区；易伤、防御、抗性、减伤正常参与。

### 3.7 欢愉伤害（欢愉命途机制）

欢愉伤害 = 技能倍率 × (1 + 欢愉度) × 笑点区 × 双暴区 × 减抗区 × 减防区 × 易伤区 × 特殊乘区

- 欢愉度通过技能、光锥、欢愉角色等提高；
- 笑点区与“阿哈时刻”、笑点值累积相关，笑点越高伤害越高；
- 双暴区重新参与，与直伤类似；
- 减抗/减防/易伤等乘区与通用伤害共享防御区、抗性区、易伤区的计算规则。

### 3.8 真实伤害

真实伤害不受乘区影响


## 4. 战技点与能量

### 4.1 战技点（Skill Point）

- 全队共享战技点池，默认上限为 5 点。部分角色（如花火）可将上限提升至 7 点。
- 释放普攻恢复 1 点战技点；释放战技消耗 1 点战技点（特殊技能可能消耗更多或产出战技点，以技能描述为准）。
- 战技点是队伍行动循环的核心资源，常规队伍构成通常围绕“耗点角色 + 产点角色”平衡。

### 4.2 能量基础回复值

角色能量通过施放技能、消灭目标、受到攻击等方式恢复。以下为常见回能表（不同角色实际可能不同）：

| 行动 | 基础能量回复 |
|---|---|
| 普通攻击 | 20 |
| 强化普通攻击 | 30 |
| 战技 | 30 |
| 终结技 | 5 |
| 追加攻击 | 0~10 |
| 消灭敌方目标 | 10 |
| 受到敌方普通攻击 | 10 |
| 受到敌方范围/蓄力攻击 | 2~25（依攻击类型） |

部分角色是特殊充能，一般表现为能量上限较低（低于60）或过高（大于1000），且技能中有大量相关说明。特殊充能不受能量恢复效率和其他效果提供回能影响，但可被“激活终结技”效果影响。

### 4.3 能量恢复效率与固定回能

能量恢复公式：

实际获得能量 = 基础能量恢复 × (100% + 能量恢复效率)

能量恢复效率来源：连结绳主词条 +19.44%（约 19.4%），部分位面饰品 2 件套 +5%，光锥效果等。

固定能量回复：部分技能/效果以固定值直接提供能量，不经过能量恢复效率乘算，或按特定规则处理：

- 固定值回能：表述为“固定回复 X 点能量”；
- 多数常规回能（技能回能、击杀回能、受击回能）受充能效率影响。

终结技具有插队机制：能量充满后可在任意时点释放，包括敌方回合；释放终结技本身不消耗该角色当回合的行动机会，也不会额外消耗回合 buff 的持续回合数（但可能触发“视为一次行动”的判定，依具体效果）。


## 5. 回合、行动值与拉条

### 5.1 行动值（AV）基础

单次行动所需行动值 = 10000 ÷ 速度
每次行动后，该单位的行动值按 10000/速度 重新累计。
行动值越低，行动越靠前、频率越高。
通过等行动值-到回合攻击的模式出伤的方式称为跑条。
通过获得额外回合、追加攻击、终结技插队的模式出伤的方式称为飞轴。
速度变化后 `新剩余行动值 = 旧剩余行动值*旧速度/新速度`

### 5.2 深渊的行动值供给

深渊各关的每一间相互独立计时。

#### 忘却之庭
首轮 150 行动值、后续每轮 100 行动值。波次切换时（转面）刷新当前轮的行动值并重置所有角色的已累计行动值（即刷新当前行动值为10000/速度）。
深渊0T指在不进入第二轮并通关，通常利用第一面150行动值，延后怪的死亡时机攒更多资源，为第二面攻坚准备。

#### 虚构叙事
每个半场固定 4 轮，首轮行动值 150，之后每轮 100，合计 450 行动值。波次切换时（转面）不刷新行动值。

#### 异相仲裁
首轮 300 行动值，后续每轮 100 行动值，轮次上限 6 轮（绝境为 2 轮）

### 5.3 拉条（行动提前）与行动延后

**行动提前（拉条）**：使单位下一次行动所需的行动值减少。
计算方法：使下一次行动所需的行动值减少 `10000*行动提前百分比/当前速度`，叠加时加算。
例：100速，已等20行动值，获得行动提前50%：还需等30行动值。

**行动延后**：使目标已累积的行动值增加，计算方向与拉条相反。量子纠缠行动延后 = 20% × (1 + 击破特攻)；虚数禁锢行动延后 = 30% × (1 + 击破特攻)。


## 6. 其他关键机制

### 6.1 效果命中与效果抵抗

实际效果命中概率 = 基础概率 × (1 + 效果命中) × (1 - 效果抵抗) × (1 - 特殊抵抗)。

精英/Boss 常见基础效果抵抗约 20%～30%，部分敌人有特殊抵抗（如可可利亚冻结抵抗额外 50%），末日兽可达 100%。

### 6.2 削韧与弱点击破

- 只有攻击敌人弱点属性时才能削减韧性；削韧值由技能决定，显示在行迹-技能描述中。
- 韧性条归零时触发“弱点击破”，造成击破伤害、施加对应属性的击破 DoT/控制效果，并使敌人进入“击破状态”，韧性区从 0.9 变为 1.0。
- 击破特攻提高击破伤害、击破 DoT 威力、行动延后幅度，但不提高削韧速度。
- 击破效率提高可以提高削韧速度。

### 6.3 防御区收益特性

减防/无视防御的收益为非线性，且不存在传统意义上的“稀释”：减防比例越高，防御区对伤害的提升比例越大。但减防总和不能使敌人防御降至 0 以下，超过 100% 的减防部分无收益。

### 6.4 常见“吃什么/不吃什么”速查

| 伤害类型 | 攻击力 | 增伤区 | 暴击区 | 击破特攻 | 易伤/防御/抗性 |
|---|---|---|---|---|---|
| 直伤 | ✓ | ✓ | ✓ | ✗ | ✓ |
| 常规 DoT | ✓ | ✓ | ✗ | ✗ | ✓ |
| 击破伤害 | ✗ | ✗ | ✗ | ✓ | ✓ |
| 超击破伤害 | ✗ | ✗ | ✗ | ✓ | ✓ |
| 欢愉伤害 | 依技能描述 | 变为欢愉度 | ✓ | ✗ | ✓ |

以上速查为通用原则，具体角色/光锥/祝福可能提供额外的特殊乘区或例外修正，Agent 调用时应优先读取技能文本中的具体描述。

## 8. Buff 覆盖率与永续 Buff

排轴的核心不是「谁先动」，而是「主 C 输出的那一刻，身上有没有叠满增益」。增益有持续回合数，而回合数只在**回合结束阶段**才 -1，所以一个持续 1 回合的 buff，只要在回合结束前用掉就还生效。

### 8.1 覆盖率怎么算

- 覆盖率 = 主 C 实际输出的回合数 ÷ 主 C 应当满 buff 输出的回合数。
- 把主 C 的每个输出回合列出来，逐一标注：身上有没有增伤、有没有降防、有没有易伤、有没有速度相关增益。
- 缺口分三类：**永远补不上**（辅助没有这个效果）、**这一轮补不上**（持续回合数不够，要等下一轮）、**顺序不对**（辅助先于主 C 行动，效果没赶上）。
- 主 C 单次输出占总伤害的比重很大时，缺一次 buff 的损失远大于「少动一次」。先排覆盖率，再排轮次。

### 8.2 持续回合数怎么算

- 常见持续回合数：施放战技的辅助给 1 回合、施放终结技的辅助给 2 回合、光锥与忆灵各有自己的上限，以工具查到的技能/光锥文本为准。
- 增益在**自己回合结束**时减 1。辅助 A 先动、B 后动、主 C 最后动：A 给 B 的 1 回合 buff，在 B 回合结束时就过期了，主 C 用不到。想让主 C 吃到，辅助必须比主 C 早动至少一轮，或者给更长的持续回合数。
- 有些增益是「下一次」型（如施放战技后，下一个行动的目标伤害提高），它跟着**下一个行动者**走，不是跟着施放者。排轴时把它算在紧随其后的那个角色身上。
- 有些增益是「施放终结技后」型（如翔鹰套的 4 件：施放终结技后行动提前 25%），它给自己加速，要算进行动顺序的迭代里。

### 8.3 永续 Buff

「永续」= 效果永远不消失，或每次都能立刻补上。永续 buff 是排轴的终点，因为它把覆盖率问题彻底消掉。

常见的永续来源：

| 类型 | 例子 | 条件 |
|---|---|---|
| 光锥常驻 | 银河铁道之夜：每有 1 个敌方目标攻击力 +9%（最多 5 层） | 目标数不减就一直在 |
| 遗器常驻 | 太空封印站 2 件：攻击力 +12% | 速度 ≥120 额外 +12% |
| 叠层可续 | 识海迷坠的学者 4 件：战技与终结技伤害 +20%，施放终结技后下一次战技额外 +25% | 每次终结技都能再叠一层「下一次战技」 |
| 队友循环 | 主 C 的战技伤害靠辅助的降防/增伤抬起来 | 辅助的 buff 持续回合数 ≥ 两轮间隔 |
| 自循环 | 角色自己的终结技给自己上 buff，再由下一次战技吃 | 角色一够能量就放 |

判断一个队伍能不能玩永续，看三件事：

1. **产出端**：增益由谁给、多久给一次（每轮？每两次行动？）。
2. **消耗端**：增益能撑几轮，够不够撑到下一次产出。
3. **衔接**：消耗速度不能快过产出速度。产出每 2 轮 1 次、消耗每轮 1 次，就永远缺。

配套做法：

- **卡双 BUFF**：把「A → C → B」的行动顺序改成「B → C」，让主 C 同时吃到两个同源继承增伤。代价是要给 B 加速（翔鹰套这类「施放终结技后行动提前」）。
- **延迟终结技**：能量满了先不放，等主 C 需要增伤的那一刻再插队放终结技。终结技插队不占行动机会，这是它最大的价值。
- **0T 的思路**：第一轮 150 行动值里尽量多攒资源（不打死怪），把增伤叠起来，第二轮一次性打出去。

### 8.4 排轴检查清单

排完一轮，对着这几条过一遍：

- [ ] 主 C 每个输出回合的增伤、降防、易伤是否都到位？缺口是「补不上」还是「顺序不对」？
- [ ] 需要靠 buff 的那一段，主 C 是第几个动的？辅助是否早于他至少一轮？
- [ ] 一次行动价值得吗？速度词条是不是刚好卡在 134/142/160/174 这些阈值上？
- [ ] 充能效率够不够多充出一个终结技？不够就是无效充能。
- [ ] 有没有把「1 回合 buff」当成了「下一轮也有」？
- [ ] 终结技的插队时机对不对？要不要故意留着不放？
