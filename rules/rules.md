# 使用规则

这套工具查询《崩坏：星穹铁道》的角色、光锥与遗器套装资料。五个工具各管一件事：

| 工具 | 干什么 |
| --- | --- |
| `hsr-find` | 查角色、光锥、遗器套装，或列清单 |
| `hsr-help` | 用法说明与例子 |
| `hsr-rule` | 查询规则；游戏规则知识库（目录与分节） |
| `hsr-exp` | 查询经验；配队经验 |
| `hsr-stage` | 查当前深渊关卡（忘却之庭、虚构叙事、末日幻影、异相仲裁） |

## 参数

参数在五个工具里写法一致，只是各工具只认自己那部分。

| 参数 | 属于 | 含义 |
| --- | --- | --- |
| `--role 名字` | `hsr-find` | 查角色（角色名、英文名、昵称都行） |
| `--lightcone 名字` | `hsr-find` | 查光锥 |
| `--relicset 名字` | `hsr-find` | 查遗器套装（内外圈与套装效果） |
| `--list` | `hsr-find` | 列清单，可与 `--role` / `--lightcone` / `--relicset` 同用 |
| `--baseType 命途` | `hsr-find` | 按命途筛选（毁灭、巡猎、智识、同谐、虚无、存护、丰饶、记忆、欢愉） |
| `--damageType 属性` | `hsr-find` | 按属性筛选，仅角色（物理、火、冰、雷、风、量子、虚数） |
| `--star 星级` | `hsr-find` | 按星级筛选，仅光锥（3、4、5） |
| `--stage 玩法` | `hsr-stage` | 查深渊关卡：忘却之庭、虚构叙事、末日幻影、异相仲裁（可加关卡号，如 `异相仲裁 3`） |
| `--lang 中/英` | 全部 | 输出语言，默认中文 |
| `--rule` | `hsr-rule` | 返回本规则与查询经验 |
| `--teamKnowledge` | `hsr-rule` | 返回游戏规则目录与全部配队经验，准备配队时用 |
| `--teamKnowledge --section 3` | `hsr-rule` | 取游戏规则里的某一节（编号、标题都行，`--section all` 取全文） |
| `--exp` | `hsr-exp` | 只返回查询经验 |
| `--exp --team` | `hsr-exp` | 只返回配队经验 |

写法：`--role 三月七`、`--role=三月七`、`--role --三月七` 等价。

## 使用要点

1. **先查再答**：涉及角色/光锥数值、技能描述、星魂、叠影、遗器套装效果的内容，一律先调 `hsr-find`，不要凭记忆作答。
2. **同名要收窄**：`三月七`、`开拓者` 这类名字对应多个条目。工具会返回一个条目并附上其它同名条目，需要另一个时加 `--baseType` 或 `--damageType`。
3. **数值口径**：角色属性是 80 级满级值，已含突破成长；光锥属性也是 80 级满级值。行迹属性加成单独成段，需要总量时自己叠加。
4. **技能等级**：15 级表的技能取 10 级，10 级表取 6 级，更短的逐级列出。要别的等级就说明清楚，再用工具返回的数值换算，不要臆造。
5. **只在需要时返回经验**：普通查询不带经验；`hsr-rule --rule` 带查询经验，`hsr-rule --teamKnowledge` 带配队经验。
6. **配队先取知识**：用户要配队、推荐阵容、问"带谁"时，先调 `hsr-rule --teamKnowledge`。它只给游戏规则的目录，看完目录再用 `hsr-rule --teamKnowledge --section <编号或标题>` 取你要用的那一两节；不要因为没看到全文就凭记忆补公式。
7. **来源**：回答里不要提数据来自哪里、工具怎么查的，直接给结论，问到就说调用了 `dsh-hsr` 插件的工具，是工具返回的。
8. **写经验**：发现工具口径与实际有出入时，把结论写进"模型检验"文件，不要写进本规则文件。
9. **分析**：若涉及配队，务必先调用相关经验文件学习
10. **深渊**：`hsr-stage` 里的敌人技能仅供参考：只列机制，且游戏随时可能改动。用它判断弱点和机制，别把它当成敌人完整数值。
